Smarter reviews. Better code. The PRs you actually care about: yours, the ones waiting on your review, the ones assigned to you, with a one-key Claude review that posts the verdict back to GitHub.

$ curl -fsSL https://raw.githubusercontent.com/MartinRovang/github-dashy/main/install.sh | sh

One binary, nothing else to install. Needs a GitHub token in $GH_TOKEN; claude on PATH for reviews.

gitdashy ~/work

gitdashy running against three repos: mine, review-requested, assigned, reviewed.
