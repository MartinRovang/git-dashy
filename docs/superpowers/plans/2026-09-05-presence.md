# Presence Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Show who on the team is online and which PRs each is reviewing, so two people do not run Claude on the same PR.

**Architecture:** A stdlib HTTP server on maze keeps an in-memory roster and sits behind `tailcat serve`. The dashboard spawns `tailcat <address> 8477` once per refresh tick and on review start/finish, writes one HTTP request to its stdin, and reads the roster back. Two module globals (`ONLINE`, `ERROR`) feed the header and the rows, mirroring how `team.NAME` / `team.ERROR` already work.

**Tech Stack:** Python 3.9 stdlib only (`http.server`, `json`, `subprocess`), curses UI, pytest. Tailcat binary on every machine.

**Spec:** `docs/superpowers/specs/2026-09-05-presence-design.md`

## Global Constraints

- Python 3.9+, stdlib only. No pip dependencies, server or client.
- Tabs for indentation, named args where the existing code uses them, `ponytail:` comments on deliberate shortcuts.
- Every subprocess that touches the network is bounded by a timeout and can never prompt.
- Nothing runs when `config.PRESENCE` is empty. Demo mode never spawns `tailcat`.
- Identity is `memory.whoami()` (the `$USER` slug the team pool already keys on). One identity for the whole app.
- Port 8477. Staleness cutoff 180 s. Client timeout 15 s.
- Commit messages end with the two attribution lines used on this branch (see `git log -1`).

```python
#!/usr/bin/env python3
"""Presence roster for gitdashy: who is online, which PRs each is reviewing.

Run on the team host behind tailcat:
    tailcat --key=presence serve 8477 &
    python3 presence_server.py

ponytail: one dict in memory, no persistence. Presence that survives a restart is stale by definition.
ponytail: binds localhost only; tailcat is the only way in, and the tailcat address is the auth.
"""
import json
import time
from http.server import BaseHTTPRequestHandler, HTTPServer

PORT = 8477
STALE = 180  # seconds since the last beat before a member drops off the roster
MAX_BODY = 4096
ROSTER = {}  # login -> {"at": epoch, "reviewing": [pr url, ...]}


def online():
	cut = time.time() - STALE
	return {"online": {u: {"reviewing": e["reviewing"]} for u, e in ROSTER.items() if e["at"] >= cut}}


class Handler(BaseHTTPRequestHandler):
	def log_message(self, *a):  # ponytail: quiet; a beat a minute per member is not news
		pass

	def _send(self, code, body):
		data = json.dumps(body).encode() if code == 200 else body.encode()
		self.send_response(code)
		self.send_header("Content-Type", "application/json" if code == 200 else "text/plain")
		self.send_header("Content-Length", str(len(data)))
		self.end_headers()
		self.wfile.write(data)

	def do_GET(self):
		self._send(200, online()) if self.path == "/" else self._send(404, "not found")

	def do_POST(self):
		if self.path != "/beat":
			return self._send(404, "not found")
		n = int(self.headers.get("Content-Length") or 0)
		if n > MAX_BODY:
			return self._send(413, "too large")
		try:
			body = json.loads(self.rfile.read(n))
			login, reviewing = body["login"], body.get("reviewing", [])
			if not isinstance(login, str) or not login or not isinstance(reviewing, list):
				raise ValueError
		except (ValueError, TypeError, KeyError):
			return self._send(400, "bad beat")
		ROSTER[login] = {"at": time.time(), "reviewing": [str(r) for r in reviewing]}
		self._send(200, online())


def main():
	HTTPServer(("127.0.0.1", PORT), Handler).serve_forever()


if __name__ == "__main__":
	main()
```

```python
# dashy/core/presence.py
"""Who is online and what they are reviewing, via the team's presence server behind tailcat.

ponytail: no socket of our own. `tailcat <address> <port>` pipes stdin/stdout to the server, so one
HTTP/1.0 request per tick goes down a subprocess and the reply comes back up. Same rule as team._remote:
bounded, never prompts, a failure is a header string not a hang.
"""
import json
import subprocess

from .. import config
from . import memory

PORT = 8477
TIMEOUT = 15  # seconds; a tick is 60 s at the fastest, so this can never overlap the next one
ONLINE = {}  # login -> [pr url, ...] as the server last said, self included
ERROR = ""  # last failure, shown in the header until the next success


def _request(body):
	data = json.dumps(body)
	return f"POST /beat HTTP/1.0\r\nHost: presence\r\nContent-Type: application/json\r\nContent-Length: {len(data.encode())}\r\n\r\n{data}"


def _parse(raw):
	"""The roster out of an HTTP/1.0 reply, or raise ValueError with the header's message."""
	head, _, body = raw.partition("\r\n\r\n")
	status = head.split("\r\n", 1)[0].split(" ", 2)
	if len(status) < 2 or status[1] != "200":
		raise ValueError(f"HTTP {status[1] if len(status) > 1 else '?'}")
	try:
		got = json.loads(body)["online"]
		return {u: list(e.get("reviewing", [])) for u, e in got.items()}
	except (ValueError, KeyError, AttributeError, TypeError):
		raise ValueError("bad reply") from None


def beat(reviewing):
	"""Tell the server what I am reviewing; learn what everyone else is. Off when PRESENCE is empty."""
	global ONLINE, ERROR
	if not config.PRESENCE:
		ONLINE, ERROR = {}, ""
		return
	try:
		r = subprocess.run(["tailcat", config.PRESENCE, str(PORT)], input=_request({"login": memory.whoami(), "reviewing": sorted(reviewing)}),
		                   capture_output=True, text=True, timeout=TIMEOUT)
	except FileNotFoundError:
		ERROR = "tailcat not installed"
		return
	except subprocess.TimeoutExpired:
		ERROR = f"timed out after {TIMEOUT}s"
		return
	except OSError as e:
		ERROR = e.strerror or str(e)
		return
	if r.returncode != 0:
		ERROR = ((r.stderr or r.stdout).strip().splitlines() or ["tailcat failed"])[-1][:60]
		return
	try:
		ONLINE, ERROR = _parse(r.stdout), ""
	except ValueError as e:
		ERROR = str(e)


def others():
	me = memory.whoami()
	return sorted(u for u in ONLINE if u != me)


def claimed(url):
	"""The other login reviewing `url`, or ''. ponytail: first match; two claimants is already the failure this prevents."""
	me = memory.whoami()
	return next((u for u, prs in sorted(ONLINE.items()) if u != me and url in prs), "")
```

def set_presence(scr, state, sel):
	"""W: the tailcat address of the team's presence server. '-' turns it off, empty keeps it."""
	new = ask(scr, state, sel, f" presence server tailcat address, or - for off [{config.PRESENCE or 'off'}]:")
	if not new:
		return
	config.PRESENCE = "" if new == "-" else new
	presence.ONLINE, presence.ERROR = {}, ""  # the old roster belonged to the old address
	config.save(snapshot(state))
	state.wake.set()  # beat now rather than at the next tick


def review_key(scr, state, sel, current):
	"""r on a REVIEW REQUESTED row: review and post, unless it is done, in flight, or someone else's."""
	if in_flight(state, current["url"]) or current["url"] in state.reviews:
		return  # already reviewed or in flight
	who = presence.claimed(current["url"])
	if who and not confirm(scr, state, sel, f" {who} is reviewing #{current['number']} right now. Review it anyway? [y/n]"):
		return
	if confirm(scr, state, sel, f" Claude review + post verdict on #{current['number']}? [y/n]"):
		state.start_review(current)
```

```markdown
### Presence

Two people should not both run Claude on the same PR. With a presence server the header shows
`Online bob, alice` and a review-requested row someone else is reviewing says `bob reviewing`; `r` on
it asks before starting a second review. Advisory, not a lock.

The server is one stdlib file, run by whoever hosts it, behind [tailcat](https://tailscale.com/tailcat):

```sh
tailcat --key=presence serve 8477 &     # prints a stable tc1q... address; share it with the team
python3 presence_server.py
```

Each member installs `tailcat`, presses `W`, and pastes the address. Plain HTTP inside the pipe is fine:
tailcat is WireGuard end to end and the address is the key, so there is no TLS and no token to manage.
The dashboard runs `tailcat <address> 8477` once per refresh and when a review starts or ends. Members
unseen for three minutes drop off. Nothing is stored on the server; a restart empties the roster.
```
